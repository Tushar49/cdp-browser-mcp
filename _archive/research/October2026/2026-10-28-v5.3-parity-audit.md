## Key landscape shift (metis)

PW-MCP now ALSO attaches to the user's real browser (extension mode +
`browser.bind()` relay, v0.0.79+). "Real browser" is eroding as a moat;
our remaining differentiation = raw CDP domain surface + lean deps +
attach-only discipline + canary-based self-description. The audit's job
is to protect those while closing agent-value gaps.

## WebAuthn follow-on design (from the 5.2 live gate's open items)

1. Event surfacing: pipeline consumes `WebAuthn.credentialAdded`/
   `credentialDeleted`/`credentialAsserted` (per-session events) →
   registry records last-activity; `list_credentials` output gains a
   "last assert" line. Wiring class identical to modal-state/webauthn
   registry cleanup (index.ts event pipeline).
2. `set_credential_properties` action → CDP `WebAuthn.setCredentialProperties`
   (authenticatorId, credentialId, backupEligible?, backupState?...).
3. Sabotage E2E without an RP server: extend the localhost rig —
   after `create()`, export the credential public key (JWK) into page
   state; the Authenticate path runs `get()` and verifies the
   assertion signature client-side via WebCrypto → shows PASS/FAIL.
   `set_override_bits isBogusSignature:true` → rig must show FAIL.
   Zero server deps; closes the 5.2 gate's one unproven path.
